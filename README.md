# Bookly — Project Management Case Study

Educational project management case study for a Telegram Mini App
for online service booking.

## About the case study

This project was created to practice IT project management:
planning, backlog management, stakeholder engagement,
risk management, and progress reporting.

This is a simulated educational case study, not a commercial
project delivered by a real team.

## My contribution

- Prepared a Project Charter and defined the project scope.
- Created a Product Backlog and Sprint Plan.
- Configured a Scrum board and JQL filters in Jira.
- Prepared a Stakeholder Map, RACI matrix, and Communication Plan.
- Identified project risks.
- Prepared a Sprint Status Report.
- Analyzed simulated sprint metrics.
- Created a bug report and technical glossary.
- Prepared AI-assisted requirements review.
- Prepared AI-assisted status summary.
